# Fortrend Backend Platform

Fortrend Backend Platform is an educational production-oriented backend project written in C++23.

The project evolves incrementally from a minimal Linux application into a high-performance distributed backend platform.

## Goals

The project is intended to develop practical skills in:

- modern C++23;
- Linux backend development;
- networking;
- asynchronous I/O;
- databases;
- distributed systems;
- high-load architecture;
- observability;
- performance engineering;
- testing and reliability.

## Current Stage

Lesson 1 — Project Bootstrap.

Current functionality:

- minimal C++23 executable;
- CMake build configuration;
- GCC and Clang build presets;
- strict compiler warnings;
- Linux development environment.

## Requirements

- Linux
- CMake 3.25+
- Ninja
- GCC or Clang
